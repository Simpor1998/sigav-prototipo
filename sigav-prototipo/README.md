# SIGAV — Prototipo de alta fidelidad

Prototipo académico del Sistema de Gestión Académica Virtual (SIGAV), desarrollado para la asignatura Modelado y Análisis de Software (Ingeniería en Sistemas Virtual, Universidad Santiago de Cali).

Incluye ocho pantallas de alta fidelidad distribuidas en tres perfiles:

- **Estudiante:** panel principal, registro de materias y pago de matrícula.
- **Profesor:** materias asignadas y registro de notas.
- **Administradora:** periodos académicos y creación de un nuevo periodo.

**Tecnologías:** HTML5, CSS3 y JavaScript vanilla. Sin frameworks ni backend; los datos son ficticios.

**Cómo abrirlo:** descarga el repositorio y abre `sigav-prototipo/index.html` en un navegador.

## Estructura

- `css/tokens.css`: paleta, tipografía y espaciado del sistema de diseño.
- `js/validaciones.js`: validación de notas, fechas y selección de materias.
